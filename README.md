# Green&Earn: Your Gamified Eco Quest

**Green&Earn** is a gamified web platform designed to turn eco-friendly actions into a rewarding adventure. By bridging the gap between sustainable choices and real-world benefits, we empower individuals and communities to make a collective impact on the planet while earning rewards from their favorite local and global partners.

---

## 🌟 Key Features

### 🎮 For Members (The Eco-Warriors)
- **Eco-Task Quests**: Browse a curated list of sustainable tasks—from recycling to tree planting—and start your journey.
- **Proof-of-Impact**: Submit photos or documentation as proof of your completed tasks to earn points.
- **Reward Marketplace**: Redeem your hard-earned points for exclusive rewards from partners like BlaBla Mart, Riot Games, and Steam.
- **Social Engagement**: Add friends, track their progress, and climb the **Global Leaderboard**.
- **Tiered Achievements**: Unlock unique **Badges** as you reach sustainability milestones.

### 🤝 For Partners (The Impact Supporters)
- **Point Awarding**: Incentivize sustainable shopping by awarding points directly to customers for eco-conscious purchases.
- **Reward Management**: Create and manage custom rewards to drive brand loyalty and environmental awareness.
- **Insight Dashboard**: Track how many eco-warriors are engaging with your brand.

### 🛡️ For Moderators & Admins
- **Verification System**: Review and approve member submissions to ensure the integrity of the platform.
- **Activity Oversight**: Create new challenges and manage the global task catalog.
- **User Management**: Comprehensive controls for maintaining a healthy and active community.

## 🚀 Tech Stack

- **Frontend**: Responsive UI built with Semantic HTML5, CSS3 (Vanilla), and JavaScript.
- **Backend**: Robust server-side logic powered by **PHP**.
- **Database**: Relational data management using **MySQL**.
- **Server**: Optimized for XAMPP/WAMP environments.

## 🛠️ Getting Started

### Prerequisites
- **Web Server**: XAMPP, WAMP, or any environment supporting PHP 8.x and MySQL.
- **Web Browser**: Latest version of Chrome, Firefox, or Edge.

### Installation
1. **Clone the Repository**:
   ```bash
   git clone https://github.com/belugawhale0912/Green-Earn-Web.git
   ```
2. **Setup the Database**:
   - Open your database management tool (e.g., phpMyAdmin).
   - Create a new database named `green_and_earn`.
   - Import the `green_and_earn.sql` file provided in the root directory.
3. **Configure Project**:
   - Move the project folder to your server's root directory (e.g., `htdocs` for XAMPP).
   - Ensure the database connection settings in your PHP files match your local environment.
4. **Run the App**:
   - Navigate to `http://localhost/GreenAndEarnWeb/php/pages/Landingpage.php` in your browser.
